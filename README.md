# Expense Tracker

A console-based Expense Tracker application developed using Java.

## 📌 Project Description

The Expense Tracker allows users to manage their daily expenses through a simple command-line interface.

Users can add, view, search, update, and delete expenses. The application also calculates total expenses and provides a category-wise expense summary.

Expense data is stored in a text file so that the data remains available even after the application is closed.

## 🚀 Features

- Add a new expense
- View all expenses
- Search expense by ID
- Update expense details
- Delete an expense
- Calculate total expenses
- View category-wise expense summary
- Save expenses to a file
- Load expenses when the application starts
- Input validation
